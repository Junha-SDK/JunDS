# i18n (`I18nProvider` + locale 사전)

- **Slug:** `i18n`
- **Status:** shipped
- **Owner:** Junha (goodjunha@gmail.com)
- **Last updated:** 2026-04-29

## Goal

JunDS 컴포넌트는 빈 상태 안내 ("데이터가 없습니다"), 토스트 라벨 ("성공"),
파일 업로드 안내 ("파일을 드래그하거나 클릭하세요") 같은 짧은 문자열을 자체적으로
포함한다. 호스트 앱이 영어로 운영하거나 자체 톤앤매너를 적용할 때 컴포넌트
포크 없이 이 문자열만 갈아끼울 수 있어야 한다. 본 사양은 그 메시지 사전
(`Locale`) 과 주입 메커니즘 (`I18nProvider` / `useI18n`) 을 정의한다.

## Scope

- In scope:
  - 기본 한국어 locale 사전 (`defaultLocale`).
  - `Locale` 타입 (사전 키 집합).
  - `I18nProvider` 의 `locale?: Partial<Locale>` 부분 override.
  - 컴포넌트 내부 사용 규약 (`useI18n()` 훅으로만 읽기).
- Out of scope:
  - 다국어 라우팅, 날짜/숫자 포맷터 (호스트 앱 책임).
  - 동적 리소스 로딩 / lazy locale 번들.
  - 메시지 보간 (현재는 단순 문자열 매핑만).
  - RTL 레이아웃.

## User stories / acceptance criteria

- [x] As a 영어권 호스트 앱 개발자, I can `<I18nProvider locale={{ close:
      "Close", cancel: "Cancel" }}>` 로 일부 메시지만 영어로 덮어써도
      나머지는 기본 한국어 사전을 그대로 받는다.
- [x] As a 라이브러리 메인테이너, 새로운 메시지 키를 추가할 때
      `defaultLocale` 한 곳에만 추가하면 전 컴포넌트가 동시에 사용 가능.
- [x] As a 컴포넌트 작성자, I can `const t = useI18n(); t.close` 처럼 키 단위로
      읽고 타입스크립트 자동완성을 받는다.
- [x] As a 호스트 앱 개발자, `I18nProvider` 를 두지 않아도 컴포넌트가
      `defaultLocale` 로 안전하게 동작한다 (Provider optional).
- [x] As a QA, 이미 사전에 정의된 키들 — common (close, cancel, confirm, save,
      delete, search, loading, noResults, noData), select (selectPlaceholder),
      pagination (prev, next), file upload (dragOrClick), empty state
      (emptyTitle), error boundary (errorTitle, retry), form (required), toast
      (success, error, warning, info) — 가 모두 한국어 디폴트로 채워져 있다.

## Design / behavior notes

- **단일 사전 모델.** 라이브러리는 영어/한국어/그 외를 정적으로 분리해 두지
  않는다. 대신 한국어 디폴트 사전 한 벌을 갖고, 호스트가 필요한 키만 부분
  override 하는 모델.
- **Partial merge.** `I18nProvider` 는 `{ ...defaultLocale, ...locale }` 로
  shallow merge 하므로 누락 키는 자동으로 한국어 디폴트로 폴백.
- **Optional Provider.** `I18nContext` 의 default value 가 `defaultLocale`
  자체이므로 Provider 가 트리에 없어도 `useI18n()` 이 안전하게 동작.
- **컴포넌트 사용 규약.** 컴포넌트 안에서 문자열을 직접 박지 않고 항상
  `useI18n()` 으로 읽는다. 새 컴포넌트가 텍스트를 노출하면 키를 `defaultLocale`
  에 먼저 추가한다.
- **타입 안전.** `Locale = typeof defaultLocale` 이라 키 추가가 타입에 즉시
  반영되며, `Partial<Locale>` override 도 키 오타를 막는다.
- **현재 정의된 키 그룹.** common / select / pagination / file upload /
  empty state / error boundary / form / toast (총 약 18개).

## Open questions

- 메시지 보간(`{count} items`) 은 v2 에서 `interpolate(msg, params)` 와
  `useT()` 헬퍼로 해결됨. 키 시그니처는 그대로 단일 문자열을 유지.
- 동적 리소스 lazy 로딩, RTL, 날짜/숫자 포맷터는 여전히 out of scope.
